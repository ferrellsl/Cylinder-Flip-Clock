This project started decades ago on Planet Source Code at (now a dead link): http://www.Planet-Source-Code.com/vb/scripts/ShowCode.asp?txtCodeId=6348&lngWId=3  It may have also been found on the Nehe OpenGL Tutorials Site

I have removed its dependencies on glaux, fixed a logic error for 12 am and 12 pm and updated the graphics to a much higher resolution for better appearance of the numbers. I've also added shading to the top and bottom of the clock to produce a more 3D appearance.

This is a flip clock where the numbers rotate around a cylinder to display the correct time.
